# TeamSync 팀원 설치 안내

> 각자 자기 노트북에서 5분이면 끝납니다.
> 설치하고 나면 **평소처럼 일하기만 하면 됩니다.** 따로 보고하거나 읽을 것이 없습니다.

**웹**: https://teamsync-ruddy.vercel.app

---

## 이게 뭘 하는 건가

각자 로컬에서 Claude Code를 띄우면 **에이전트들이 서로의 존재를 모릅니다.** 그래서
사람이 눈 역할을 대신하죠 — git log 훑고, 슬랙에 묻고, "저 이거 바꿨어요"를 알리고.

TeamSync는 그 중계기 노릇을 없앱니다.

```
당신이 세션을 끝냄  →  요약이 자동 생성됨  →  동료가 다음 세션을 시작할 때
                                              그 사람 에이전트에게 자동으로 들어감
```

동료는 **아무것도 읽지 않습니다.** 그 사람의 에이전트가 이미 알고 시작합니다.

---

## 1단계 · 가입하고 프로젝트에 참여

1. https://teamsync-ruddy.vercel.app 접속 → **회원가입**
   - 이름은 실명이나 평소 쓰는 호칭으로. **동료의 에이전트가 이 이름으로 당신을 부릅니다.**
2. 팀장에게 받은 **6자리 참여 코드**를 입력해 참여

참여하면 **당신 전용 훅 토큰**이 발급됩니다. 팀이 하나를 나눠 쓰는 게 아니라
사람마다 다릅니다.

---

## 2단계 · 훅 설치

프로젝트 화면에 **당신의 설치 명령**이 그대로 나옵니다. `토큰 보기` 를 누르고 복사하세요.

```sh
# TeamSync 저장소를 받아서
git clone https://github.com/jungee123213/unithon-2026.git ~/teamsync
cd ~/teamsync

# 프로젝트 화면에서 복사한 명령을 붙여넣기 (경로만 본인 것으로)
TEAMSYNC_TOKEN=tsk_... \
  ./hooks/install.sh ~/work/우리프로젝트 지우 hankki https://teamsync-ruddy.vercel.app
```

`~/work/우리프로젝트` 자리에 **연동하려는 폴더 경로**를 넣으세요.

> **중요:** 여기서 지정한 **그 폴더**에서 `claude` 를 띄웠을 때만 동작합니다.
> 다른 폴더에서 하는 작업은 전송되지 않습니다.

설치되는 것:
- `<폴더>/.claude/hooks/teamsync/` — 훅 스크립트
- `<폴더>/.claude/settings.json` — 당신의 토큰과 이름

## 3단계 · 확인

그 폴더에서 평소처럼 Claude Code를 쓰세요. 세션을 끝낼 때(`/clear` 하거나 창을 닫을 때)
전송됩니다.

```sh
cd ~/work/우리프로젝트
claude
# ... 평소처럼 작업 ...
# /clear 또는 창 닫기
```

**웹의 디버그 창**에서 도착했는지 바로 보입니다:
https://teamsync-ruddy.vercel.app/p/<프로젝트ID>/debug

로컬 로그로도 볼 수 있습니다:

```sh
tail -20 ~/.claude/teamsync/teamsync.log
```

## 무엇이 전송되고 무엇이 전송되지 않는가

**필터링도 자동입니다.** 사람이 매번 판단하면 그게 또 일이 되니까요.

| 계층 | 규칙 |
|---|---|
| **폴더** | 훅을 설치한 폴더에서만 동작 |
| **브랜치** | `main` · `develop` · `feature/*` 에서만 전송. **개인 실험 브랜치는 자동 제외** |
| **내용** | 요약 AI가 "팀에 영향 있나"를 판정. 없으면 아예 저장 안 함 |
| **비밀정보** | API 키·토큰·이메일은 프롬프트로 한 번, 정규식으로 한 번 총 두 번 걸러냄 |

디버그 창에서 `건너뜀 · 팀에 영향 없다고 판정` 이 뜨는 건 **정상입니다.**
모든 세션이 공유되지는 않습니다.

### 잠깐 끄고 싶을 때

```sh
touch ~/work/우리프로젝트/.teamsync-off      # 끄기 (쓰기·읽기 모두 중단)
rm ~/work/우리프로젝트/.teamsync-off         # 다시 켜기
```

### 개인 브랜치에서 작업할 때

```sh
git checkout -b wip/실험
# 여기서 한 작업은 전송되지 않습니다. 아무 설정도 필요 없습니다.
```

## 문제가 생기면

**아무 일도 안 일어나는 것 같다**

```sh
tail -20 ~/.claude/teamsync/teamsync.log
```

로그 자체가 없다면 훅이 안 걸린 겁니다. 그 폴더에 `.claude/settings.json` 이 있는지 확인하세요.

**자세히 보고 싶다**

`.claude/settings.json` 의 `env` 에 `"TEAMSYNC_DEBUG": "1"` 을 추가하면
훅이 숨기던 에러를 전부 로그에 남깁니다.

**토큰이 새어 나갔다**

프로젝트 화면 → `토큰 재발급`. 재발급하면 훅을 다시 설치해야 합니다.

## 자주 나오는 질문

**Q. 내 코드가 어디로 가나요?**
코드는 전송되지 않습니다. 에이전트가 남긴 **요약문**만 갑니다.
디버그 창과 Team Space에서 실제로 저장된 문장을 그대로 볼 수 있습니다.

**Q. 다른 프로젝트 작업이 섞이지 않나요?**
섞이지 않습니다. 훅은 설치한 폴더에서만 돌고, 토큰이 프로젝트를 결정합니다.
다른 프로젝트로 밀어넣는 경로가 없습니다.

**Q. 세션 끝날 때 느려지나요?**
아니요. 전송은 완전히 분리된 프로세스로 나가서 세션 종료를 붙잡지 않습니다.

**Q. 내가 받은 정보를 어디서 보나요?**
Team Space의 **영수증**이 당신에게 실제로 주입된 문자열을 그대로 보여줍니다.
다만 굳이 볼 필요는 없습니다 — 이미 당신의 에이전트에게 들어가 있습니다.
